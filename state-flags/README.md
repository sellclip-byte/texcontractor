# State flag avatar assets

Flags cover all 50 U.S. states and the District of Columbia.
Source: https://github.com/Invoxio/us-state-flags/tree/master/flags/us
Source pattern: flags/us/{state-code}/{state-code}.svg
Retrieved October 18, 2026. Artwork is rendered at 288 × 192 for small
avatars and embedded in self-contained SVG files to keep requests local.
Original aspect ratios are standardized to 3:2 for the circular avatar crop.
These are geographic backgrounds, not contractor photos or business logos.
